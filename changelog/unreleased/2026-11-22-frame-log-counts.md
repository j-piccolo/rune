- Frame-profile builds on Linux: each line of `RUNE_FRAME_LOG` now carries the CPU's own counts since the last frame, in user space: `cyc` and `ins`, the drawing thread's cycles and instructions, and `cyc_all` and `ins_all`, every thread's. A time reads whatever else the machine was doing and whatever clock the core had; a cycle ticks only while the thread runs, and an instruction count is the same every run, so two builds compare on a busy machine.
