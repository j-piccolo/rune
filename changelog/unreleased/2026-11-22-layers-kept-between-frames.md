- A layer whose contents didn't change is no longer drawn into its texture again each frame: a fade changes a group's opacity on every frame and nothing inside it, so the frame now only composites the texture it drew last. It holds for plain layers (no blur, no turn, no layer or effect inside) while nothing but instances draws into them, and a write to the glyph atlas, the outline store or an image page draws them again. `RUNE_LAYER_KEEP=0` draws every layer every frame, as before.
