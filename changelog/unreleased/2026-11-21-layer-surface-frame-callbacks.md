- Linux: a layer-shell or session-lock surface the compositor is not drawing (under a fullscreen window, on an output asleep) no longer holds up the app's other surfaces. Each one's next frame waits for the compositor's frame callback for its last instead of for a present with vsync, which waited on the thread they all draw on: with niri, a second per frame of a covered bar, during which a popup opening on another output stood still. The loop no longer polls while a layer surface animates.
