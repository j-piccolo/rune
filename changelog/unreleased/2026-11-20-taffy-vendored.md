- Taffy is vendored (`vendor/taffy`: 0.15.1 as published plus `vendor/taffy.patch`, re-made by `scripts/vendor-taffy.sh`) as a plain path dependency, so apps need no `[patch.crates-io]` entry, and an app whose lockfile held taffy 0.15.0 now lays out with 0.15.1. The patch measures a flex item's automatic minimum size (`min-width: auto`) only when it can change the layout, which leaves layout as it was: a row of fixed-size items, such as a rail of cards a virtual list mounts, no longer lays out each item's subtree at min-content first.
